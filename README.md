# WetterCheck

Schulprojekt MTSP, 3ITM 2026/27, Alexander Brodesser und Lukas Gruber

Website: https://alexanderbrodesser.github.io/wettercheck/

Zeigt das aktuelle Wetter, eine Vorhersage (1 bis 7 Tage mit Slider) und welche Kleidung passt (grün) oder nicht passt (rot).

## Starten

`index.html` im Browser öffnen.

## Dateien

- `index.html`: Startseite mit Wetter, Vorhersage und Kleidung
- `kontakt.html`: Kontaktformular
- `impressum.html`, `datenschutz.html`
- `css/style.css`
- `js/app.js`: Wetter laden und anzeigen
- `js/kontakt.js`: Kontaktformular
- `bilder/`: Bilder der Kleidungsstücke (selbst gezeichnet)
