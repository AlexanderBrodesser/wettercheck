Hosting

Die Seite liegt auf GitHub Pages (GitHub Inc.). GitHub verarbeitet dabei technische Daten wie die IP-Adresse, damit die Seite angezeigt werden kann.

Wetterdaten

Der Browser fragt das Wetter direkt bei Open-Meteo.com ab. Dabei werden die IP-Adresse und der eingegebene Ort übertragen.

Hintergrundvideos

Die Videos im Hintergrund der Startseite werden direkt von Pexels (pexels.com) geladen. Dabei wird deine IP-Adresse an Pexels übertragen.

Standort

Wenn du auf "Mein Standort" klickst, fragt der Browser um Erlaubnis. Nur wenn du zustimmst, werden deine Koordinaten für die Wetterabfrage an Open-Meteo.com geschickt. Wir speichern den Standort nicht.

Kontaktformular

Das Formular schickt nichts selbst ab. Es öffnet nur dein E-Mail-Programm. Was du dann schickst, landet in unseren Schul-Postfächern.

Letzter Ort

Der zuletzt gesuchte Ort wird im Speicher deines Browsers (localStorage) abgelegt, damit er beim nächsten Besuch gleich angezeigt wird. Er bleibt auf deinem Gerät.

Was wir nicht machen

Keine Cookies, kein Tracking, keine Speicherung von Daten auf eigenen Servern.

Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung und Löschung. Beschwerden sind bei der Österreichischen Datenschutzbehörde (dsb.gv.at) möglich.
